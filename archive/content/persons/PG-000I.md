# 钟不惑

恩索685(?)-

No. PG-000I
:::

我们可以从口口相传中确定有钟不惑这样一个人，但我们很难拿出物证证实这样一个人确实存在。这或许很令人惊讶。

我们可以在那西索亚共和国居民身份档案中调取到钟不惑的身份信息，但找不到任何一张关于他的清晰的正面照片。

在见过钟不惑的人中，关于他的外貌论述产生了极大的分歧，这就产生了一个问题：一个人能否同时拥有全然不同的外貌？

如果说这是化妆所致，在齐若烟所著的《忏悔录》中，则有这样一条古怪的记述：
:::note
一个七八岁的小孩涉雪走过来。大冬天的，他一身的短袖短裤，皮肤冷的跟雪一样白，上面张牙舞爪几道紫红的血管。
我立马站起来。

小孩看向我。

我“啊”地一声，声音卡在嗓子眼。

我确定肯定那是钟不惑。[^3]

（恩索718年）
:::

按照时间推断，恩索718年，钟不惑已经32到33岁。他为何能以一个七八岁的孩童外貌出现？

而从后文中这个孩子的言行来看，他确实是钟不惑。

[^3]:齐若烟，《忏悔录》，安奎尔：那西索亚文学出版社，第198页
:::

:::page

对于钟不惑的存在性争议，曾有人提出有趣的看法：“钟不惑”这个名字是一群人的自称。他们同时对外界宣称这个名字，因此他们的外貌总在变化。

至于为何一个“假身份”还存在亲缘关系，这是因为“钟不惑”这个人确实存在。或者说曾经存在。他是数学学者钟声晚之子，古生物学家吴铮的养子。最开始只有他一个人使用这个名字，不知何时发展成了一个组织。

也正是这群人，发明了**通用机**。[^4]

遗憾的是，这个假定是不成立的。因为在恩索718年前后，钟不惑以七八岁的孩童外貌出现时，他原有的朋友和亲人都认定他是本来的钟不惑。

[^4]:赵风，《谁发明了通用机》，朱邦：南方文艺出版社

:::

恩索685年，钟不惑出生在布拉克特大学附近的金门学者公寓。

在钟不惑出生之后不久——也许是立刻。他的父亲钟声晚在同一间卧室里用刀横向割开自己的腹部，自杀身亡。

当地一家热衷搜集奇闻轶事因而臭名昭彰的小报详尽而夸张地记述了这一事件：

:::quote
“...一男子活生生用刀剖开自己的肚子——他的肚子里内脏都被挤瘪了，与此同时一个满身是血的婴儿被放在一边的床上。难道这世界上真有男性生子这样的奇事吗？还是其中有何隐情...“

— 《布拉克特奇事报》
:::

恩索685年至691年，钟不惑跟随母亲方汀在布拉克特过着艰苦清贫的生活。

方汀在夜间酒馆做服务员，过着长期昼夜颠倒的生活。长期与酒为伴的生活让她患上了严重的酒精依赖症和酒精性肝硬化。

恩索691年夏，方汀在他们所租住的公寓中因肝硬化不治离世。巧合的是，吴铮因调查其父陈思忧的死因上门拜访方汀。他和他的朋友联系了治安所移走方汀的尸体——在此之前，钟不惑至少和母亲的尸体单独相处了两天。

从恩索691年起，吴铮开始担当抚养和照顾钟不惑的工作。
