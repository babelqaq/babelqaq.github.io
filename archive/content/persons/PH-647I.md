# 钟声晚

恩索647-685

数学学者

No. PH-647I
:::

:::year
647
:::

恩索647年，钟声晚出生在安奎尔。

钟声晚的父亲来自离伊万顿不远的斯旺托，母亲则来自布拉克特。

恩索642年，钟声晚的姑姑钟胜男跟随友人齐山海来到安奎尔，在安奎尔的某家书社担任前台。一年后，她通过社会招考进入恩索文理大学分析机学院修读计算科学。

恩索645年，钟声晚的父亲也来到安奎尔，并在齐山海的帮助下成为一位小有名气的商人。

:::

:::page

恩索647年，钟声晚在安奎尔父母的家里出生。因为出生的太过于匆忙，他们没来得及去医院。

钟声晚的姑姑钟胜男似乎比其他任何人都更早得知了钟声晚的出生，实际上，在钟声晚的父母结婚当日，钟胜男就预言了这对夫妇会生下三个儿子。

钟胜男曾告诉钟声晚的父母，在三个儿子中，只有小儿子最为聪明，是“点睛之笔”。其他两个儿子都不过碌碌之辈。

钟声晚的父母对钟胜男的预言坚信不疑，早在怀上第一个孩子时，就给三个孩子定下名字。三个孩子分别名为：“在林”“在寺”“声晚”。

三个孩子的名字源自古地球的诗文“苍苍竹林寺，杳杳钟声晚。”

从3岁开始，钟声晚的聪明灵慧就在父母的一众亲朋好友间传开了。

在钟声晚6岁左右，他对生物的迁徙现象产生了很大的兴趣。作为生物学家的高鸿极为欢迎他来跟随自己研究。

就在同一时期，20岁的陈思忧也在跟随高鸿学习。年龄相差极大的两个人就此成为了几乎同级的师兄弟。

:::note

或许，当然只是或许，从这一时刻开始，陈思忧就已经产生了对钟声晚的嫉妒之心。这使得他和钟声晚的关系长期以来都处于一个微妙的状态。

不负众望，钟声晚在14岁时进入恩索文理大学数学学院学习。他的专业非常广泛，几乎没有一个明确的主攻方向。

:::year
662
:::

进入恩索文理大学次年，钟声晚取得了极为宝贵的前往恩索城留学的资格，前往传说中的贤者之城精进他的智慧。

:::year
667
:::

钟声晚从恩索城回到安奎尔，顺利取得学士学位，并与来自恩索城的女友方汀[^1]按那西索亚习俗结婚。[^2]



[^1]:“方汀”这个名字并非方汀的本名，而是她的那西索亚名。她的本名已不可考。
[^2]:恩索人没有结婚的习俗，也没有婚姻制度。恩索人普遍认为用一段婚姻关系将两个人绑定并组成家庭是奇怪的。恩索人也没有家庭的概念。
:::

:::page

同年9月，钟声晚加入布拉克特大学数学学院，担任学者。
