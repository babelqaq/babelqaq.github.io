# 齐山海
恩索607(?)-696

那西索亚共和国议会，议长

No. PN-001K-a
:::

:::facts
| ---- | ---- |
| 出生 | 恩索607年，伊万顿 |
| 逝世 | 恩索696年，安奎尔 |
:::

:::year
607
:::

恩索607年，齐山海出生于伊万顿[^1]，临近北方弗拉索斯国的一处边境村庄。该村庄地处边远，居民保留着极为原始的宗教信仰，崇拜梵迦(ΦKÂ)神。

这里的居民有此信仰很可能是由于他们中的大多数都是NÂKÏ而非人类。

[^1]:齐山海的出生年代很可能远早于恩索607年。作为NÂKÏ，齐山海至少拥有普通人类3-4倍的寿命，并且热衷于变换身份。
:::

:::page
:::year
637
:::

齐山海的整个青年时代都在伊万顿的边境担任村庄祭司，并在恩索637年和妻子胡海媚生下第一个孩子齐之艮。

:::year
639-641
:::

恩索639年，高鸿、高若兰夫妇来到伊万顿边境进行科学考察。齐山海主动欢迎他们到来，并担任他们的向导。

这一科学考察为期2年，期间，高鸿夫妇和齐山海结下了深厚的友谊。

:::year
642
:::

恩索642年，高若兰主动邀请齐山海加入那西索亚历史研究所，担任顾问。
:::

:::page

:::year
646
:::

恩索646年秋，齐山海兼职政府文史顾问，参与地方改革项目。


:::year
649
:::

恩索649年夏4月，齐山海借调至国家立法研究处。

:::year
653-657
:::

恩索653年，齐山海参选北安奎尔选区议员并成功当选。

恩索657年，齐山海连任议员。

:::year
659-665
:::

恩索659年，齐山海当选议会议长。

:::

:::page
恩索661年及663年，齐山海先后连任议长，到达最长任期。于恩索665年结束任期，回到议会担任中立议员。

:::year
669
:::

恩索669年3月，时任议长的白仲人因大规模减税政策，引发金锡暴跌，全国经济动荡，被迫引咎辞职。

6月，在白仲人的继任者也政策不利的情况下，那西索亚各大城市爆发了大规模抗议游行，谴责政府无能。

8月11日，在安奎尔，数千人走上街头，要求齐山海重新上台。

9月7日，议会紧急通过了一项议案，使得齐山海再度获得任职期限并担任临时议长。

:::

:::page

齐山海上任后，很快推出长期财政修复计划，并进行债务管理优化。

齐山海的重新执政很大程度上给那西索亚的国民带来了信心，同年12月，那西索亚共和国议会正式宣布齐山海担任议长，并获得新的2年任期。

:::year
671
:::

恩索671年，在议会支持票数超过三分之二，及全民公投通过的情况下，齐山海得以修改宪章，将那西索亚共和国议会议长的最高任职年限提高到了原定6年的两倍，即12年。

:::year
675
:::

恩索675年，齐山海再次到达议长最长任期。这次，齐山海选择离开议会，并辞去一切政务工作，退休居家。

:::
