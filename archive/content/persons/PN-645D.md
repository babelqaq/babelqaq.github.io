# 齐之巽

恩索645-

建筑设计师

No. PN-645D
:::

:::year
645
:::

恩索645年，齐之巽出生在安奎尔。

最广为人知的说法是，齐之巽的父亲是齐山海，母亲是齐山海的妻子胡海媚。但从亲缘关系上看，齐之巽显然不是齐山海和胡海媚的孩子。

齐之巽的儿子许同尘拥有白色毛皮和三条尾巴，而齐之巽的丈夫许著闻属于人类。这一性状显然无法来自许著闻。

并且这一独特的性状与齐山海和胡海媚都不相符。

:::

:::page

:::year
663
:::

恩索663年，齐之巽进入安奎尔文史大学文学院，并于当年年末退学，转入布拉克特建筑设计院工作。

:::year
665
:::

恩索665年7月，齐之巽结识自由撰稿人许著闻。两人在相识13天后，在没有告知家人的情况下迅速结婚。

:::year
667
:::

齐之巽为高雅、陈思忧夫妇在安奎尔郊外设计了一处别墅，名为林中之馆。

该别墅在恩索667年起建，668年3月完工。

恩索670年10月17日，齐之巽在首都医院生下一对龙凤胎。姐姐名为许和光，弟弟名为许同尘。

10月21日，许和光因新生儿肺炎离世。

齐之巽饱受产后抑郁及精神分裂症的影响，先后在当年12月与次年6月于首都医院精神科住院治疗。

在精神分裂症的影响下，齐之巽认为自己能找到一个方法复活女儿。

671
:::
